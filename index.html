A FOCUSED PLUGIN

独立 MPP。清晰的职责边界。

MPP 可以独立于 mobile-dev-harness（mdh）构建和使用，专注设备预览与输入。验证引擎、自动化 agent 工具与模型视觉，不在这个面板的职责内。

  • ↗原版 DSH 即可接入视频和输入无需修改 DSH 源码；侧栏宽度由用户手动调整。
  • ↗设备连接在 Host 一侧Web 展示 DSH Host 上的设备，不会自动访问浏览器所在机器。
  • ↗画面不自动进入模型上下文插件不注册 agent 工具；内部 stdio 桥接也不是 MCP。

VIDEO PATH

设备端采集并编码 H.264，经 MPP1 二进制媒体通道、Rust Host 与 DSH 认证 streaming Fetch 到达客户端，由 WebCodecs 解码。Host 和 Node 层不解码、不重新编码。

⌘生命周期独立管理 DSH Host 插件 ↔ JSON-lines stdio ↔ Rust 会话、启动、状态与停止。实时输入无需排在启动等慢任务之后。

小入口，原生设备端

Java bootstrap 仅准备 Looper、加载 Rust 动态库并进入原生入口。采集、编码、传输、输入和清理均由 Rust 实现。

可追踪的会话边界

连接绑定 adb transport ID；租约 generation 与采集 epoch 分开。旧输入与旧回调不能操作新采集，几何变化会终止当前采集。

复用已有认证

客户端经 DSH 认证 HTTP 接口接收视频与提交有界输入批次，无需新增供浏览器直连的未认证监听端口。

03 / GET STARTED

准备好设备，开始预览。

当前为开发预览，公共安装包尚未发布。
以下步骤用于取得预览包后。

BEFORE YOU CONNECT

运行环境

  • Apple Silicon · macOS 14+当前包仅包含 darwin-arm64 Host。
  • Android SDK platform-toolsHost 上可用的 adb，以及已授权的 arm64 Android 设备。
  • DeepSeek HarnessWeb 或 Desktop；客户端需要 H.264 WebCodecs 支持。
  • 现有 AVD（使用模拟器时）需要 emulator 组件与已创建的 AVD，启动时明确选择。
DeepSeek 官方下载 ↗（新窗口）

使用自带运行文件的预览包，不需要安装 Rust、NDK 或 JDK。

01

取得并核对预览包

准备实际收到的 .tgz、相邻 SHA-256 文件与包内 runtime-manifest.json，核对版本、构建目标和文件摘要。校验和用于完整性与溯源，不是签名。

02

安装、启用，再重启 Host

在插件管理器中添加本地归档，或使用 Web CLI。更换原生包版本后，重启 DSH Host，让新运行文件生效。

在归档所在目录运行，将 preview-package.tgz 替换为实际文件名。

dsh plugin --profile web add "$PWD/preview-package.tgz"
Plugins→Add plugin→本地 .tgz

输入预览包的绝对路径，安装并启用。这个插件管理器流程也适用于 Web 界面。

03

打开面板，连接一个明确的设备

在聊天中打开移动设备面板，选择已授权设备并点击 Connect。面板可见时自动开始预览；在屏幕区域内点击、拖动，或使用 Home / Back。

04

按需暂停，结束后断开

Pause 保持主动暂停，Resume 恢复。有效连接在面板隐藏后可恢复预览；租约过期需重新连接。断开不会关闭模拟器。

移除插件 +

先断开设备，再通过插件管理器移除。Web CLI 使用安装时的同一 profile：

dsh plugin --profile web remove @mobile-dev-harness/dsh-mobile-preview

当前边界

Know before you connect
PLATFORM

先从 Android 开始

当前包仅提供 macOS arm64 Host；Linux / Windows 安装包与 iOS 后端尚未提供。API 29–37 是实现范围，不是全设备承诺。

INTERACTION

聚焦画面与基础输入

音频、录制、多点触摸、任意文本 / IME 和剪贴板集成未实现。旋转或显示几何变化会结束当前采集。

QUALIFICATION

持续补齐真实场景

更多厂商、真机 USB 热拔插、长时间 GUI 运行与完整性能测量仍需覆盖。当前不承诺固定帧率、延迟或所有设备兼容。

实现与运行的补充说明 +

Android API 29–33 使用 SurfaceControl / InputManager 路径；API 34–37 使用 DisplayManager mirror / InputManagerGlobal 路径。隐藏接口与厂商差异需要逐目标验收。

连接租约过期后需要重新连接；重启 adb server 后需重启 MPP Host。官方 Desktop 已验证系统窗口缩放、面板重开、暂停恢复和 GUI 卸载 / 重装。暂停及卸载后没有遗留 helper 或 adb reverse 映射，重新安装可恢复预览；Web API 37 已验证窄视口与宽视口切换无需手动启动。Web 在 API 35 连接后完成 GUI 卸载，设备入口与旧视图移除，插件依赖 / bundle、helper 和 adb reverse 均已清理；Web 在 API 35 重装、启用并重新连接后已恢复 Live 预览。操作系统最小化 / 后台返回、侧栏拆分 / 浮动及长时间运行仍需单独覆盖。

MPP 参考 scrcpy 的视频与控制分离思路，但不运行、分发、依赖 scrcpy，也不兼容其通信协议。自动按手机比例调整侧栏宽度属于可选本地 DSH UI 扩展，尚不是上游公开 API。
